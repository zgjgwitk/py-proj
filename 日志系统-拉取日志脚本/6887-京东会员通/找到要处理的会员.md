## 需求3: 过滤标签1中不紧急的数据
*脚本名称*
- 生成新的py脚本 "过滤标签1中不紧急的数据.py"
- 参考 "急需处理的会员.py"来实现新的功能

*脚本功能*
1. 读取文件"D:\Github\py-proj\日志系统-拉取日志脚本\根据指定条件拉取日志Message\6887-京东会员通\tofilter_flag1.csv"
2. 然后读取['BindVipId'],['Old_CdpId']列的数据, 生成sql语句去 6887品牌的 ezp-crm库查询
   - sql1:
    ``` sql
    SELECT * FROM `crm_vip_info_third_party_bind` WHERE BrandId=6887 AND ThirdPartyId=1 AND VipId=${BindVipId}
    ```
   - sql2:
    ``` sql
    SELEC * FROM `crm_jd_order_total_temp` WHERE BrandId=6887 AND (VipId=${BindVipId} OR CdpId='${Old_CdpId}')
    ORDER BY VipId,CreateDate
    ```
3. 按照"查询结果处理"里面的方法做数据分析, 如果处理结果是返回'10',则将此数据写入新的csv文件,并且['TempErrType']列标识为 10;

*查询结果处理*
1. 定义 sql1 的查询结果为 'QueryData1'
2. 定义 sql2 的查询结果为 'QueryData2'
3. 'QueryData2' 根据 'ORDER BY VipId,CreateDate' 这个方式排序下得到结果 'ListData2'
4. 筛选出'ListData2'中 `CdpId=${Old_CdpId}` 的最后一条记录 oldData
5. 筛选出'ListData2'中 `VipId=${BindVipId} && CdpId=QueryData1.CustomerIdentity ` 的第一条记录 newData
6. 对比 oldData.TotalOrderPrice == newData.TotalOrderPrice, 如果相等就返回10, 否则返回0
